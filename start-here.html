PATH 01 / DATA & AI

From first notebook to data project.

Learn to ask a useful question, work with data and explain a result. No previous coding experience required.

Your eight-week route

Use Google Colab or Kaggle Notebooks so you can practise in a browser. Keep one notebook as your project journal.

BEGINNER · 3–5 HRS/WEEK
FINISH LINE

Publish a notebook with one clear question, a cited dataset, a chart or model, a plain-language result, limitations and a next step.

  1. Set up and learn Python basics

    Open a notebook, run code cells and practise variables, lists, conditions and loops. Save three small examples.

    Start Kaggle's Python lessons ↗

  2. Load and inspect a dataset

    Read a CSV, inspect columns and types, count missing values and write down what each row represents.

    Practise with pandas ↗

  3. Choose a question and data

    Pick a question you can answer with available columns. Record the dataset name, source, date and licence or reuse terms.

    Explore open global data ↗

  4. Clean and describe the data

    Check duplicates, missing values and unusual records. Calculate simple counts, averages or percentages that relate to your question.

    Learn data cleaning ↗

  5. Make a chart that answers something

    Choose a chart that fits your question, label it clearly and write two sentences describing what it shows.

    Learn data visualization ↗

  6. Build a simple baseline model

    Try one beginner model, keep some data aside for validation and compare your result with a simple baseline.

    Start machine learning ↗

  7. Check the result and its limits

    Change one thing at a time. Check for leakage, explain uncertainty and record what your data cannot tell you.

    Understand evaluation and rules ↗

  8. Publish a clear project story

    Add a title, question, source, method, result, limitations and next step. Make sure someone else can run your notebook.

    Study example notebooks ↗

Project idea: Explore a trend in health, education, climate or public services using a public dataset. Share the evidence, not just the model score.

PATH 02 / WEB DEVELOPMENT

From first page to published site.

Build a small, useful website from scratch. Learn how the page is structured, styled, made interactive and shared online.

Your eight-week route

Work in a browser-based editor or a computer you can access. Keep each week's work in one folder and use GitHub to save versions.

BEGINNER · 3–5 HRS/WEEK
FINISH LINE

Publish a responsive, accessible website for a club, project or topic you care about, with a clear homepage, useful content and a simple portfolio write-up.

  1. Understand HTML structure

    Build a page with a title, headings, paragraphs, links, lists and images. Use headings in a logical order.

    Learn HTML structure ↗

  2. Style a page with CSS

    Set colours, spacing, type and readable widths. Use a small set of design choices consistently.

    Learn CSS basics ↗

  3. Make it work on a phone

    Use flexible layouts, test a narrow screen and make links and buttons easy to tap.

    Follow a web foundations path ↗

  4. Add JavaScript fundamentals

    Practise values, functions, conditions and events. Add one small interaction with a clear purpose.

    Practise JavaScript ↗

  5. Make the page accessible

    Use descriptive link text, keyboard-friendly controls, visible focus and enough contrast. Add labels to form fields.

    Learn web accessibility ↗

  6. Save work with Git and GitHub

    Create a repository, add a clear README and save meaningful versions as you improve the site.

    Practise GitHub collaboration ↗

  7. Test with real people

    Ask two people to find one piece of information. Observe where they get stuck and improve the page.

    Use the MDN learning path ↗

  8. Publish and explain it

    Deploy the site, check every link and write a short note about the audience, design choices and what you would improve next.

    Publish with GitHub Pages ↗

Project idea: Create a practical guide for a local club, class or community. Include clear contact or next-step information without publishing anyone's private details.

PATH 03 / RESEARCH & SCIENCE

From curiosity to evidence.

Turn a question into a small, careful investigation. Practise finding trustworthy sources, recording a method and communicating what the evidence supports.

Your eight-week route

Use a public dataset or an established classroom simulation. Keep the question manageable and the method safe, ethical and repeatable.

BEGINNER · 3–5 HRS/WEEK
FINISH LINE

Share a short research brief with a focused question, source notes, a repeatable method, one chart or table, a conclusion, limitations and references.

  1. Turn curiosity into one question

    Choose something observable and specific. Write what you already think, what evidence would change your mind and what you will measure.

    Explore OpenLearn study resources ↗

  2. Find and record reliable sources

    Read more than one source. Note author, date, evidence, possible limits and a link so you can return to it.

    Find research papers ↗

  3. Plan a fair investigation

    Choose a public dataset or a safe simulation. Define the variables and comparison before looking for the result.

    Explore science simulations ↗

  4. Collect or select evidence carefully

    Record where the data came from, units, dates and selection choices. Avoid collecting private information about people.

    Browse documented public data ↗

  5. Organize and check your observations

    Make a tidy table, check for missing or unusual values, and keep a note of any correction you make.

    Explore research datasets ↗

  6. Analyse and show one result

    Calculate a comparison or summary and make one labelled chart. Describe the pattern before explaining why it might exist.

    Practise clear data charts ↗

  7. Discuss limits and other explanations

    Ask what could be missing, what else might explain the pattern and what conclusion would be too strong.

    Check related research ↗

  8. Write and share a research brief

    Explain the question, sources, method, result, limits and references in plain language. Include enough detail for another learner to repeat your steps.

    Organize research references ↗

Project idea: Compare a public trend across two places or time periods. Describe the evidence and limits without claiming that a simple comparison proves cause and effect.
